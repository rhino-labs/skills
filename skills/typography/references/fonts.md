# Font Selection Guide

## Choosing Fonts

Professional fonts provide the most visible upgrade to typography. A well-chosen font provides designer expertise without designer costs.

## Font Categories to Avoid

- **System defaults** for final documents (Times New Roman, Arial, Calibri)
- **Goofy/novelty fonts** (Comic Sans, Papyrus, Curlz)
- **Monospaced fonts** for body text (Courier) — reserve for code
- **Most free fonts** — low quality; exceptions exist (see below)

## Recommended Professional Fonts

### Serif (body text, print documents)
- **Equity** — versatile text face
- **Valkyrie** — sturdy, authoritative
- **Century Supra** — modernized Century family
- **Charter** (free, high quality) — good default when budget is limited

### Sans Serif (headings, UI, presentations)
- **Concourse** — clean, professional sans
- **Heliotrope** — humanist sans

### Monospace (code, technical)
- **Triplicate** — proportional feel in a monospace design

### Display/Specialty
- **Advocate** — headline and display use
- **Hermes Maia** — distinctive character

## Mixing Fonts

- Mixing is optional — vary weight, size, and style within one font family first
- Maximum 2 fonts per document; 3 is rare; 4+ never works
- Assign each font a consistent role (e.g., one for body, one for headings)
- Keep different fonts in separate paragraphs
- Fonts by the same designer pair reliably well
- Low contrast between fonts often works better than high contrast

## Font Size Matching

When switching fonts, match visually rather than numerically:
1. Set a text block in both fonts at the same point size
2. Adjust the new font until line breaks align similarly
3. Use half-point increments for fine-tuning

## System Font Acceptable Uses

- Email drafts
- Internal memos and notes
- Quick documents not intended for external audiences
